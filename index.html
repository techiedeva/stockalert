Get free SMS alerts via Twilio — 5 min setup
1
Create a free Twilio account
Go to twilio.com/try-twilio and sign up. No credit card required. You get $15 trial credit — enough for hundreds of SMS messages.
2
Verify your phone number
During signup Twilio asks you to verify your personal number. On the free trial you can only send SMS to verified numbers. This is the number that will receive your alerts.
3
Get a Twilio phone number (free on trial)
In the Twilio Console go to Phone Numbers → Manage → Buy a Number. Pick any number with SMS capability. This is your "From" number.
4
Create a Twilio Function as SMS proxy
In the Twilio Console go to Functions & Assets → Services → Create Service. Name it sms-alert. Add a function at path /send and paste this code, then click Deploy:
exports.handler = function(context, event, callback) { const client = context.getTwilioClient(); client.messages.create({ body: event.body, from: event.from, to: event.to }).then(msg => callback(null, { sid: msg.sid })) .catch(err => callback(err)); };
After deploying, copy the Function URL — it looks like https://sms-alert-XXXX.twil.io/send. Paste it below.
